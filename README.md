# Kingdom Life Study - book packs

This repository is the library the Kingdom Life Study app downloads from.

- `catalog.json` is the index the app reads.
- `packs/*.json` are the books themselves.

Nothing here is edited by hand. Both are generated by `pipeline/publish.py`
in the study-guide project; publishing a book is:

    python3 pipeline/publish.py
    cd publish && git add -A && git commit -m "publish" && git push

The app fetches `catalog.json` over raw.githubusercontent.com, compares each
book's version against what is stored on the device, and shows an Install or
Update button accordingly. Books already installed keep working with no network
at all.

Scripture is the World English Bible, which is in the public domain.
